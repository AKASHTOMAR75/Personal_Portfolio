# Akash Tomar | Generative AI & ML Developer Portfolio

![Portfolio Preview](public/favicon.svg) <!-- Replace with an actual screenshot of the portfolio if desired -->

A modern, highly interactive personal portfolio built with **React** and **Vite**. This portfolio is designed with premium "glassmorphism" aesthetics, smooth scroll animations, and dynamic UI elements to showcase my experience in **Generative AI, Large Language Models (LLMs), and Machine Learning**.

## 🚀 Features

- **Premium Aesthetics:** Custom dark mode UI with glassmorphism cards, vibrant gradients, and dynamic background glow effects.
- **Interactive Hero Section:** Features a dynamic typing effect and a terminal window visualization demonstrating a Python AI model script.
- **Scroll Animations:** Smooth fade-in and slide-up animations powered by the Intersection Observer API.
- **Fully Responsive:** Adapts seamlessly to all screen sizes and mobile devices with a built-in mobile navigation menu.
- **Comprehensive Sections:** Includes sections for About, Skills, Projects, and an Experience/Education timeline.

## 🛠️ Tech Stack

- **Framework:** [React 18](https://react.dev/) powered by [Vite](https://vitejs.dev/)
- **Styling:** Vanilla CSS (Custom properties, Flexbox/Grid, Animations)
- **Typography:** Google Fonts (Inter & Outfit)
- **Icons:** FontAwesome

## 💻 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AKASHTOMAR75/Personal_Portfolio.git
   cd Personal_Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the app:**
   Open your browser and navigate to `http://localhost:5173` (or the port provided in your terminal).
